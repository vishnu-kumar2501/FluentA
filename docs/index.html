Windows Installation Guide
Windows 10 / 11
  1. 1
    Download & Run Setup

    Download FluentASetup.exe and double-click to launch the installer.

  2. 2
    Windows SmartScreen Notice

    On initial launch, Windows Defender SmartScreen may display: "Windows protected your PC" because FluentA is an independent, newly published app.

    Click More info → Click Run anyway. FluentA is 100% clean, verified, and telemetry-free.
  3. 3
    Instant Proofreading Anywhere

    FluentA starts automatically in your system tray. Highlight any sentence in Word, Slack, WhatsApp, or Chrome, and press:

    Ctrl + Alt + G
Linux Installation & Setup Guide
Ubuntu / Debian / Universal
  1. 1
    Download & Extract the Archive

    Download fluenta-linux-amd64.tar.gz and extract it in terminal:

    tar -xzf fluenta-linux-amd64.tar.gz cd fluenta-linux-amd64
  2. 2
    Run the Automated Installer

    Execute the installer with root privileges to install the desktop app and CLI to /usr/bin:

    sudo chmod +x install.sh sudo ./install.sh

    Zero lock issues: Installs directly to system paths without waiting for apt/dpkg package manager locks.

  3. 3
    Launch the Desktop GUI

    Launch FluentA directly from your Applications menu, or start the background process via terminal:

    fluenta-desktop &

    Note: FluentA enforces single-instance locking. If it shows "already running", the background daemon is already active and healthy.

  4. 4
    Configure the Global Shortcut (Ctrl + Alt + G)

    On Linux (GNOME/Ubuntu/Wayland), custom hotkeys are assigned in system settings:

    1. Open Settings → Keyboard → Keyboard Shortcuts → Custom Shortcuts (or click +).
    2. Name: FluentA Replace
    3. Command: /usr/bin/fluenta --selection --replace
    4. Shortcut: Press Ctrl + Alt + G

    Now highlight any text in any Linux application and press Ctrl+Alt+G for instant in-place proofreading.

  5. 5
    Terminal / Pipe CLI Usage

    You can also use FluentA directly from any shell or script:

    # Direct proofreading fluenta "She dont know nothing about programming." # Pipeline proofreading echo "Please find attached reports what you asked" | fluenta --mode concise
Linux Troubleshooting Tips
  • Permission Denied on install.sh: Run chmod +x install.sh before executing.
  • Already Running: fluenta-desktop is a background service and prevents duplicate instances automatically.
  • Missing clipboard utility: On X11, install xclip (sudo apt install xclip xdotool). On Wayland, install wl-clipboard (sudo apt install wl-clipboard).
